# OpenCV Image Operations & Edge Detection

A Python script built with **OpenCV** and **NumPy** demonstrating core Image Processing and Computer Vision fundamentals.

## Features Covered
* **Image Resizing:** Uniform resizing of input images using `cv2.resize`.
* **Image Arithmetic & Logic:** Code examples for weighted addition (`cv2.addWeighted`), subtraction, and bitwise operations (`AND`, `OR`, `XOR`, `NOT`).
* **NumPy Array Stacking:** Horizontal and vertical image concatenation using `np.hstack` and `np.vstack`.
* **Edge Detection:** Implementation of **Canny Edge Detection** with fine-tuned parameters (`apertureSize=3`, `L2gradient=True`).
